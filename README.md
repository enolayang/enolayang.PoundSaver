## 📖 项目简介

**羊毛镑 (PoundSaver)** 是一款专为关注英镑汇率变动、有英镑兑换与消费需求的用户量身打造的轻量级 Web 应用。产品完美结合了**硬核实用工具**与**游戏化互动养成（小羊肖恩 IP）**，通过科学的分批规划、实时的多周期趋势看板以及趣味性的打卡任务，帮助用户在波动频繁的外汇市场中“薅”到属于自己的每一笔实惠。

---

## ✨ 核心功能亮点

* **🎯 多身份定制空间**
  * **留学生专属**：学费分批规划器、生活费预算拆解。
  * **海淘党专属**：英淘到手价精算器、转运费与税费预估。
  * **英国旅游者**：高频消费场景换算、DCC（动态货币转换）避坑指南。
* **📊 实时行情与多周期趋势**
  * 支持多周期趋势看板与移动平均线（MA）参考，轻松洞察汇率波段。
* **🧮 羊毛战果评估器**
  * 实时换算省下的真金白银，让每一分汇率差价都有迹可循。
* **🎮 游戏化互动体验**
  * **跟着肖恩猜涨跌**：每日打卡竞猜汇率走势。
  * **牧羊币商店 & 牧场养成**：通过日常打卡与换算赚取牧羊币，解锁趣味互动与专属徽章。
